## Supplementary folder 11 
contains all the results from the analysis module for individual dictionaries, including 
[disease](analysis_covid-19/),
[virus](analysis_Sars_cov2/),
[variant](analysis_SarsCov2_variant/), 
[mutation](analysis_SarsCov2_mutation/).
For the variant dictionary, results include both entries [with](analysis_Sarscov2_variant_full/)  and [without](analysis_SarsCov2_variant/) 1–2 character terms.
Additionally, we calculated the total count of each entity class separately using [modified analysis module](../Supplemental_file5/analysis.py) on the merged files.
The resulting data and plots are saved in the [analysis_merged](analysis_merged) folder.
